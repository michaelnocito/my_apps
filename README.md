# My Learning Apps

Free, self-contained learning apps. Each one is a single HTML page that runs in your browser. No account, no install.

**Start here:** `index.html` (the menu of all apps)

## Apps

**API and integrations**
- API Crash Course: foundations, endpoints, JSON, status codes
- API Support Tickets: realistic troubleshooting scenarios
- JSON for Field Mappers: types, nesting, syntax, tickets
- JSON Arrays Deep Dive: arrays and nested data
- Endpoints Deep Dive: URLs, methods, parameters, environments
- API Practice Lab: a simulated API to send and fix requests

**SQL**
- SNES SQL Practice: hands-on queries, one step at a time

**Implementation**
- SaaS Implementation Lab: process, migration, UAT, go-live
- Fast-Track Implementation Lab: right-sizing a long implementation
- Project Momentum Lab: unresponsive customers and records

**Learning**
- Learn Faster, Remember Longer: memory science for tech learning
- Learning Science: Fundamentals: memory, attention, and retention
- Anticipation Lab: anticipation, avoidance, and practical tools
- Study Dashboard: one syllabus with daily review scheduling
- Five Rings: Musashi's strategy for daily life

## Notes

- Progress is saved in your own browser on your own device. Nothing is sent anywhere.
- All people, companies, and data in the examples are fictional.
- The Anticipation Lab and Learning Science apps are educational only, not medical or therapy advice.
