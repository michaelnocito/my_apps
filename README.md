# My Learning Apps

These are all experimental. Designed to be small, digestible learning apps. 
Free, self-contained learning apps. 
Each one is a single HTML page that runs in your browser. No account, no install.

## Start here: the Study Dashboard

**Why:** learning sticks when you review it at the right time. The [Study Dashboard](https://michaelnocito.github.io/my_apps/study-dashboard.html) does the scheduling for you. It tells you what to review today and what to learn next, using spaced repetition (reviews at 1, 3, 7, 14, 30, and 60 days). Missed items come back sooner.

**Set it up (2 minutes):**
1. Open the Study Dashboard.
2. Go to **Paths**, then **Import from app library**. Tick the apps you want and tap **Import selected**.
3. Add your own items too, with or without a link (outside apps, books, videos, music apps). Open a path and use **Add one item**.
4. Each day, open **Today**. Review what's due first (try to recall it before you check), then learn one new thing and tap **Learned it today**.

**Good to know:**
- Your progress is saved in your own browser on your own device. Use **Backup / restore** on the Paths screen to keep a copy.
- On a phone, use your browser's **Add to Home Screen** to open it like an app.
- New apps added to the library show up in the import list automatically.

Or skip the dashboard and open any app directly from the menu: `index.html`
